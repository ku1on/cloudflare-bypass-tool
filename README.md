# CloudFlare Bypass Tool

![Version](https://img.shields.io/badge/version-2.2-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## Описание

CloudFlare Bypass Tool - это веб-приложение, которое помогает обнаружить реальный IP-адрес веб-сайтов, защищенных CloudFlare. Инструмент анализирует DNS-записи и использует различные методы для определения фактического IP-адреса сервера, скрытого за CloudFlare.

## Особенности

- Определение реального IP-адреса за CloudFlare
- Получение информации о DNS-серверах
- Геолокация IP-адреса (страна, город, координаты)
- Информация о хостинг-провайдере
- Современный интерфейс в стиле Apple с карточным дизайном

## Установка и запуск

### Предварительные требования

- Веб-браузер
- Python 3.x (для запуска локального сервера)

### Запуск

1. Клонируйте репозиторий или скачайте файлы проекта

```bash
git clone https://github.com/yourusername/cloudflare-bypass-tool.git
cd cloudflare-bypass-tool
```

2. Запустите локальный веб-сервер

```bash
python3 -m http.server 8000
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

## Использование

1. Введите домен целевого сайта в поле ввода (например, example.com)
2. Нажмите кнопку "Scan"
3. Дождитесь завершения анализа
4. Просмотрите результаты, включая:
   - IP-адрес CloudFlare
   - DNS-серверы CloudFlare
   - Реальный IP-адрес сервера
   - Информацию о хостинге и геолокации

## Ограничения

Обратите внимание, что не все веб-сайты, защищенные CloudFlare, могут быть проанализированы с помощью этого инструмента. Эффективность зависит от конфигурации безопасности целевого сайта.

## Технические детали

Приложение использует следующие API:

- Google DNS API для получения DNS-записей
- IPGeolocation API для получения информации о геолокации IP-адреса
